## Status

 **Build Status:** In Development  
 **Known Issues:** Several bugs and errors are present in the current build  
 **Production Ready:** No  


---

## Stack

| Layer | Technology |
|---|---|
| Desktop App | Electron + React + Tailwind CSS |
| Code Editor | Monaco Editor |
| Code Runner | Piston API |
| Backend | Node.js + Express + Socket.io |
| Database | Supabase (PostgreSQL) |
| Admin Dashboard | React + Tailwind CSS |

---


## Project Structure
```
gridlock/
├── app/          Electron desktop app (participants)
├── backend/      Node.js + Express + Socket.io
├── admin/        React admin dashboard
└── scripts/      DB seeding and team code generation
```
